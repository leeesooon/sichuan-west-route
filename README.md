# 川西低拥堵 7 天 6 夜自驾路线

这是一个可直接打开的静态路线图，入口文件是 `index.html`。

## 内容

- `index.html`：交互地图、7 天行程、里程、驾驶时间、海拔、风险和备选点图鉴。
- `route-assets/`：页面实际引用的本地景观图片。
- `川西低拥堵7天6夜自驾路线图.pdf`：当前路线图 PDF 版。
- `reports/`：国庆川西自驾风险评估报告及其 PDF 版。
- `archive/`：之前的深度路线版本，仅作对照留档。

## 使用

直接打开 `index.html` 即可查看。交互地图需要网络加载 Leaflet 和 OpenStreetMap 底图；上方路线示意图、行程卡片和本地图片不依赖地图服务。

页面中的图片来源链接位于每张图下方。小红书图片仅作为个人行程视觉参考，版权归原作者和平台；Wikimedia Commons 图片按各自来源页面的许可信息使用。

里程、时间、开放状态和道路风险都是出发前的规划参考，实际行程需要重新核对天气、交通管制、景区开放、补给和住宿。
